Access AutoServer

During install you choose a listen port (default 8000) and optionally a domain. The service listens on 0.0.0.0:PORT so you can reach it by public IP, domain, or SSH tunnel.

Public IP or domain

Open the URL printed at the end of install, for example:

http://YOUR_SERVER_IP:8000/login
http://panel.example.com:8000/login
  • Allow the port in the VPS firewall / security group.
  • HTTPS on a custom port needs a reverse proxy later; install shows http:// until then.
  • Leave Secure cookies unchecked on first setup unless HTTPS already works.

SSH tunnel (local)

Keep traffic private on your laptop:

ssh -L 8000:127.0.0.1:8000 root@YOUR_SERVER_IP

# then open http://127.0.0.1:8000/login
  • Leave the SSH session open while you use the UI.
  • If the tunnel drops during setup Save (connection reset), reconnect SSH and retry — this is usually the tunnel, not a corrupt install.
  • If you changed PORT, use that port on both sides of -L.
