Access AutoServer

During install you choose a listen port (default 8000) and optionally a domain/subdomain. How you open the UI depends on that choice.

1. Domain + HTTPS (recommended)

If you enter a domain/subdomain and accept Caddy HTTPS, install configures Caddy with a Let's Encrypt certificate and reverse-proxies to the app on localhost. Open: 

https://panel.example.com/login
  • DNS A/AAAA for the domain/subdomain must already point to this VPS before install.
  • Firewall should allow 80 and 443 (install opens them when UFW is active).
  • The app binds 127.0.0.1:PORT; public traffic goes through Caddy only.
  • Secure cookies are enabled automatically (COOKIE_SECURE=1).
  • Skip HTTPS at install with --no-https, or answer n when prompted — then use the HTTP URL below.

2. Public IP (no domain)

Open the URL printed at the end of install, for example:

http://YOUR_SERVER_IP:8000/login
  • Allow the app port in the VPS firewall / security group.
  • Leave Secure cookies unchecked unless you terminate TLS yourself.

3. Domain without HTTPS

If you set a domain/subdomain but skipped Caddy:

http://panel.example.com:8000/login
  • Same as IP access: app listens on 0.0.0.0:PORT.
  • You can re-run install with the domain later, or add a reverse proxy yourself.

4. SSH tunnel (local)

Keep traffic private on your laptop (works even when the app is bound to localhost):

ssh -L 8000:127.0.0.1:8000 root@YOUR_SERVER_IP

# then open http://127.0.0.1:8000/login
  • Leave the SSH session open while you use the UI.
  • If the tunnel drops during setup Save (connection reset), reconnect SSH and retry - this is usually the tunnel, not a corrupt install.
  • If you changed PORT, use that port on both sides of -L.
