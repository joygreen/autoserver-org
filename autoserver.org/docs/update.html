Update

curl -fsSL https://autoserver.org/update.sh | bash

Checks the installed version against the latest release. If already current, it exits. If newer is available, it asks for confirmation, then updates in place.

Options

# Skip confirmation
curl -fsSL https://autoserver.org/update.sh | bash -s -- --yes

# Update to a specific version
curl -fsSL https://autoserver.org/update.sh | bash -s -- --version 0.1.1
