Uninstall

curl -fsSL https://autoserver.org/uninstall.sh | bash

This removes /opt/autoserver and the systemd unit. It does not unbind your license key.

To reuse the key on another VPS: Dashboard → Unbind machine → install again with the same key.

Machine identity stays in /var/lib/autoserver so a reinstall on the same box can bind again. Remove it only if you intend a fresh identity:

rm -rf /var/lib/autoserver
