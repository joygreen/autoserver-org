Uninstall

curl -fsSL https://autoserver.org/uninstall.sh | bash

Removes /opt/autoserver and the systemd unit, and unbinds the license key on autoserver.org (key-row becomes unbound; IP / domain / VPS info is cleared).

  • Confirm with yes when prompted.
  • Reinstall on the same VPS or another VPS with the same key works after unbind.
  • Machine identity stays in /var/lib/autoserver unless you purge it.

Options

# Keep key bound in the dashboard (skip remote unbind)
curl -fsSL https://autoserver.org/uninstall.sh | bash -s -- --keep-bound

# Also delete machine identity (new fingerprint on next install)
curl -fsSL https://autoserver.org/uninstall.sh | bash -s -- --purge-identity
