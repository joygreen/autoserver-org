VPS requirements

  • Ubuntu 22.04+ or Debian (root SSH)
  • ~1 GB RAM (installer can add 1G swap if needed)

Without a domain, keep chat private and open it from IP Address or your laptop via SSH tunnel — see Local access. 

https://your-domain:8000
http://your-ipaddress:8000
ssh -L 8000:127.0.0.1:8000 root@your-ipserver
# then http://localhost:8000
# change port 8000 as selected during installation
