VPS requirements

  • Ubuntu 22.04+ or Debian (root SSH)
  • ~1 GB RAM (installer can add 1G swap if needed)
  • Python 3.10+
  • Outbound HTTPS to autoserver.org (license bind + download)
  • Ports 80/443 if you want public HTTPS via Caddy

Without a domain, keep chat private and open it from your laptop via SSH tunnel — see Local access. 

ssh -L 8000:127.0.0.1:8000 user@your-server
# then http://localhost:8000
